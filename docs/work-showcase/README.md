# Deskbot 工作展示网页

静态网页，无需安装依赖或连接模型。包括七个工作方向、ASR/TTS 交互图表、语音链路、上下文与播放机制、阶段时间线、验证记录和演示提词。

## 打开

- 最便捷：用浏览器打开 `deskbot-presentation.html`，这是包含样式、脚本和讲稿下载的单文件离线版本。
- 开发版本：浏览器打开 `index.html`，或在仓库根目录运行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory docs
```

随后访问 `http://127.0.0.1:8765/work-showcase/`。

## 演讲操作

- 点击右上角“演讲模式”，从当前章节开始逐页展示。
- 左右方向键或底部箭头翻页；Esc 退出演讲模式。
- “讲稿”显示当前页提示；该提示与页面一起显示，投屏时观众也可看到。
- “全屏”调用浏览器全屏功能，是否允许取决于浏览器。
- 模型实验可切换 ASR/TTS 和比较指标；时间线、架构步骤和演示提词可以点击切换。
- 演示提词和链路动画仅解释交互过程，不会连接设备或发送指令。

## 文件与数据

- `index.html`：内容与页面结构。
- `styles.css`：响应式布局、演讲和打印样式。
- `app.js`：历史实验数值、图表和页面交互。
- `deskbot-presentation.html`：从上述三份源文件生成的离线交付版本；后续编辑优先修改源文件，再重新生成。
- 完整依据及逐页讲稿：`../server-voice-work-summary-2026-10-16.md`。

模型数据来自历史聊天保存的正式实验输出，原 JSON/CSV 本次未找回。自动化测试数量来自 2026-10-11 的记录；本网页制作没有重新跑模型实验或硬件验收。2026-11-02 将网页与讲稿纳入仓库；未部署独立网页服务。
