# Deskbot 本地语音服务器工作记录

更新时间：2026-10-02

## 2026-10-11 本地语音服务稳定性与动作边界

- 增加可配置的本地命令 TTS：命令从 stdin 读取 UTF-8 文本，向 stdout 输出 24 kHz 单声道 s16le PCM；Edge TTS 仍为默认 Provider。
- 增加 `/readyz` 启动就绪检查、LLM 重试配置、发送超时、WebSocket 帧上限和同设备旧会话替换。
- 实机 MCP 受 `mcp.enabled` 和 `allowed_device_tools` 双重控制；运动调用限制时长，取消或断开时尽力发送停止命令。
- 记忆增加简单相关历史检索和每设备原始消息保留上限；SQLite 在初始化时启用 WAL，并为连接设置 busy timeout。
- 修复“向前走一秒”等直接运动指令未命中解析、LLM 空回复无音频的问题。
- 回归结果：342 项 Python、16 项浏览器逻辑、7 项启动器测试通过；真实模型、Edge 网络和原生硬件仍需现场验收。

## 当前服务

- `8000`：设备语音 WebSocket，路径为 `/xiaozhi/v1/`。
- `8003`：OTA 配置与健康检查，设备地址为 `http://<服务器局域网地址>:8003/xiaozhi/ota/`。
- `8004`：仅监听本机的管理 API，提供在线会话和设备历史记录查询。
- `8006`：浏览器本地测试页，使用 `http://127.0.0.1:8006/` 打开。

## 已完成的服务器工作

- 管理 API 增加在线会话列表，测试页每 2 秒刷新设备 ID、会话 ID、连接时长和当前阶段，支持多台实机同时连接。
- 对话历史按 `Device-Id` 隔离保存，测试页可以加载当前设备或指定设备的最近消息和记忆摘要。
- `auto` 和 `realtime` 监听模式在一轮 `tts.stop` 后自动重新进入监听；`manual` 模式保持原有的再次唤醒流程。
- 默认对话回复限制为最多三句话、每句话尽量不超过 60 个汉字，并继续按句生成语音。
- 面向实机的 Opus 音频包按 60 ms 音频帧节奏发送，避免长回复一次性涌入设备播放队列；浏览器测试桥仍由浏览器本地调度。
- 本地测试页保留摄像头 MCP、视觉对话、健康检查、日志导出和模型选择功能；启动器可以选择 ninfer、Ollama 或智谱模式并打开测试页。
- 实机 MCP 已接入语音工具循环：设备在 hello 中声明 `features.mcp=true` 后，服务器会读取工具清单，将运动、IMU 和实机摄像头工具提供给模型，并通过原 WebSocket 转发调用结果。运动调用限制为 1 到 5000 毫秒；设备断开时清理待处理请求。
- 立创实战派固件的相机在启动后延迟初始化；已在延迟初始化完成后注册 `self.camera.take_photo`，否则服务端只能发现运动和传感器工具。刷入包含该修复的固件后，重新连接设备即可在卡片中看到拍照工具。

## 验证记录

- Python 测试：331 项通过；浏览器逻辑测试 15 项通过；启动器回归 7 项通过。
- 实测 OTA 返回 `ws://<服务器局域网地址>:8000/xiaozhi/v1/`，至少一台实机已成功建立会话；在线设备列表显示设备 MAC 作为 `Device-Id`。
- 多台设备的并发 WebSocket 握手已通过服务端测试，服务端没有单设备数量限制。

## 已知运行条件

- 设备与服务器必须在同一个局域网，OTA 地址中的服务器 IP 需要使用服务器当前局域网地址。
- 浏览器测试页要使用 HTTP 地址，直接打开 `file:///.../index.html` 时不会正常读取本地 API。
- 语音对话还依赖配置的 LLM 和 Edge TTS。“服务暂时不可用”是通用错误提示，需要根据设备卡片的失败阶段和 voice.log 区分识别、模型、工具或合成问题。


## 2026-10-02 设备工具与界面整体修复

- 补全 MCP initialize、视觉上传能力下发、初始化通知与所有 tools/list 分页，按会话缓存，避免每次说话重复发现。
- 修正固件 hello 的 text_font 兼容、工具函数名的模型别名、true/false/JSON 文本返回的成功失败识别；实机相机与浏览器相机按会话区分。
- OTA HTTP 服务新增 `/mcp/vision/explain`，接收固件 chunked multipart 图片，调用当前视觉模型并把真实描述返回设备；图片不落盘。
- 设备卡显示 MCP 状态、工具清单、最近调用及单轮 ASR/文字/语音耗时。新增仅供本机使用的三种状态查询，可验证完整设备往返。
- Edge TTS 改为流式转码，保持 Opus 下行节奏并在打断时回收 FFmpeg。短句单次网络对比首 PCM 由 2.702 秒变为 2.325 秒；不作为固定延迟保证。
- 启动器修复相对路径进程遗漏、重复停止、Tk 主线程等待和 TIME_WAIT 假端口冲突；桌面启动/停止使用统一进程识别；最近成功模式保存到 selection.json。日志保存到 `~/.local/state/deskbot/`。
- 模型在线验证：当前 glm-4-flash 已正确返回 device_self_sensor_get_imu 调用。服务已使用“智谱云端 · 视觉版”重新启动，语音、OTA、管理 API 和测试页端口均正常。本次重启后尚无真实设备重连，实机姿态读取、运动和拍照仍待设备唤醒后验收；协议回归测试不等于硬件验收。
